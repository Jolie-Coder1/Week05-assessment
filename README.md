Assessment Parts

Part A: Predictions, Bug Fixes, and Short Answers

Contains predicted JavaScript outputs, corrected buggy code, and explanations of JavaScript concepts in answers.md.

Part B: Member Information Formatting

Formats member names, phone numbers, and savings using JavaScript strings and numbers.

Part C: Savings Analysis

Uses conditions, switch statements, and loops to classify members, calculate total savings, and count members meeting a savings target.

Part D: Functions and Report Generation

Implements and tests eight reusable functions, then uses them to generate a complete savings report.

Part E: Code Quality and Documentation

Includes code cleanup, testing, project documentation, a screenshot, and version control using Git.

Testing

The program should be tested with different savings amounts and member details.

Test cases should include:

A member with savings below the target.

A member who meets the savings target.

A member with savings above the target.

An empty member list when calculating the average.

Invalid savings values, where required by the assessment.

Expected results should be compared with the actual output in the browser console.
